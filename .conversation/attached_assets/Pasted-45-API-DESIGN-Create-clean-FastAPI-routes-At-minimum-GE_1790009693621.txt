47. PERFORMANCE

The prototype should feel fast.

Do NOT run a 5,000-iteration Monte Carlo simulation every time the user opens a dashboard page.

Precompute baseline risk results.

Run Monte Carlo asynchronously or cache results.

Only run simulations when:

scenario changes
risk-relevant telemetry changes
user explicitly requests simulation

Use caching.
